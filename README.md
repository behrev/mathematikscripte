# Mathescripte für Smartphone (ursprünglich für Pocket PC)

Willkommen bei den **Mathescripte**, einer Sammlung von JavaScript-basierten Werkzeugen zur mathematischen Berechnung, die speziell für die Anzeige auf Pocket PCs optimiert wurden. Diese Tools sind ideal für Studierende der Elektrotechnik geeignet, um schnell Gleichungssysteme zu lösen oder Determinanten zu berechnen.

## 🚀 Features
Die Seite bietet verschiedene mathematische Funktionen direkt im Browser an:

*   **Quadratische Gleichungen:** Löse quadratische Gleichungen mit der abc-Formel, inklusive Berechnung des Scheitelpunktes und Darstellung in der Scheitelpunktform.
*   **Lineare Gleichungssysteme (n=2):** Berechne Lösungen für Gleichungssysteme mit zwei Variablen.
*   **Lineare Gleichungssysteme (n=3):** Löse Gleichungssysteme mit drei Variablen und berechne gleichzeitig die Determinante der Matrix.
*   **Determinanten (n=4):** Berechne die Determinante einer 4x4-Matrix.
*   **Taschenrechner:** Ein klassischer Rechner für schnelle Grundrechenarten.

## 🛠 Technische Details
- **Technologien:** HTML, JavaScript (für Berechnungen), CSS (einfaches Styling).
- **Optimierung:** Die Skripte sind so gestaltet, dass sie auch im *Pocket Internet Explorer* auf Pocket PCs flüssig laufen.
- **Eingabe:** Für Dezimalzahlen verwenden Sie bitte ein Komma (`,`) als Dezimaltrennzeichen.

## 📖 Anleitung
1. Öffne die `index.html` in deinem Browser.
2. Wähle aus der Tabelle das gewünschte mathematische Problem aus.
3. Gib die entsprechenden Werte in die Textfelder ein.
4. Klicke auf den Button **"ausrechnen"** oder **"Lösen"**, um das Ergebnis anzuzeigen.

## 📂 Dateistruktur
- `index.html`: Hauptmenü mit allen verfügbaren Funktionen.
- `quagl.htm`: Löser für quadratische Gleichungen.
- `gl2.htm`: Löser für Gleichungssysteme mit 2 Variablen.
- `gl3.htm`: Löser für Gleichungssysteme mit 3 Variablen.
- `det4.htm`: Berechner für 4x4-Determinanten.
- `rechner/calculator.html`: Klassischer Taschenrechner.

## ⚠️ Hinweis
Damit die Skripte funktionieren, muss in deinem Browser die Ausführung von JavaScript aktiviert sein.
